🏆 3. Quick Reference: Most Frequent Viva Questions & Model Answers
Viva Question Ideal Technical Answer
Why choose Context API over Redux for state management? "For a project of this scale, Redux introduces significant boilerplate, extra actions, and bundle overhead. React's native Context API, partitioned into modular providers (Auth, Expenses, Theme, Socket), provides lightweight global state management with clean separation of concerns and zero external dependencies."
How does JWT authentication work end-to-end? "Upon valid login credentials, the server signs a JSON payload containing the user's ID and role using HMAC-SHA256 and an environment secret. The client receives this token and attaches it to subsequent requests in the Authorization: Bearer <token> header. The server verifies this token using middleware before granting access."
Why use compound indexing in MongoDB? "Our primary queries filter by the logged-in user and sort by transaction date ({ user: 1, date: -1 }). A compound index allows MongoDB to resolve both the filter and the sort order directly in B-tree memory without performing expensive collection-wide scans."
Why use WebSockets instead of periodic HTTP polling? "HTTP polling creates continuous overhead with repeated TCP handshakes and header payloads even when no new data exists. WebSockets maintain a single persistent full-duplex connection, allowing the server to push events (new expenses, budget threshold alerts, chat messages) to the client with sub-millisecond latency."
What is the advantage of a multi-stage Docker build? "A single-stage build would leave Node.js, npm cache, and source files inside the production container, resulting in images exceeding 800MB. Multi-stage builds compile the static assets in Stage 1, then copy only the compiled static bundle into a lightweight Nginx Alpine container in Stage 2, reducing the production image to under 25MB."
